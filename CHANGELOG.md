# Changelog

## Unreleased

- Tabs drop the hover pill. Hovering (or keyboard-focusing) an unselected tab now fades its label and icon to the selected tab's text color, and the selected pill only moves on click. Hover is plain CSS (`group-hover/tab`), so there is no pointer tracking and it stays off for touch.
- Input gains `variant="filled"`: a muted wash with no border, deepening a little on hover and focus. The default stays the hairline border on a lifted surface. Invalid still draws a destructive edge on either. The docs sidebar search uses it to filter nav items as you type, and `SidebarInput` defaults to filled.
- Badge is a new component on the Data Foundations pastel palette: soft tags (the chart-key look), plus a muted neutral when `color` is omitted. Soft tags are a translucent wash (~18% light / ~10% dark) over the local surface from `useSurface()`, so the tint stays stable on colored or raised parents. `size="lg"` steps up padding and type for denser labels. The six hues and their tag tokens live in `lib/chart-palette`, which `data-display` and `badge` both depend on.
- Lisse surfaces no longer flash square corners on load. `useCornerRef` and overlays set a CSS `border-radius` fallback from `cornersCssRadius` for SSR and first paint; once the clip-path is ready, `border-radius: 0 !important` keeps React from putting the fallback back and squaring the squircle.
- Surfaces and raised controls share a top inner highlight: `--shadow-inset-hi` (`inset 0 1px 0 0 rgba(255, 255, 255, 0.08)`), always on. It leads every `--shadow-*` stack so Lisse Elevated and overlays pick it up, and Default, Primary, and Toggle buttons use the same inset. Dark mode drops the old thin `--dm-hi-*` top edge in favor of this highlight; ring insets and outer drops stay.
- Tooltip and menu exits fade the Lisse shadow with the panel. The origin-aware zoom stays on the popup, and the squircle surface is drawn inside it, the same split as the sheet. A tooltip arrow goes inside the popup, above that shadow and outside the clip.
- Button animates content changes, after microinteractions.dev's text swap. When the text, an icon, or a loading spinner changes, the old content slides down 120%, fades, and blurs to 5px while the new content enters from above, over 220ms on `cubic-bezier(0.23, 1, 0.32, 1)`. The button width eases between the two, and the button clips its content only during the swap. Changes are detected from the text and element types of `children`, so re-renders with the same content don't animate, and nothing animates on mount. Reduced motion crossfades in 150ms. Inline-icon padding now ignores the outgoing content and eases with the swap.
- Sidebar menu buttons leave room for a `SidebarMenuBadge`, so long labels truncate before the badge instead of running under it.
- Sidebar resizes. Set `resize` on `SidebarProvider` (or `AppShell`) and `SidebarRail` becomes a drag handle that still toggles on click. `resize="fixed"` keeps one width: let go past halfway to hide it, or drag out from hidden to open it at that width. `resize="learn"` resizes between `minWidth` and `maxWidth`, records each released width, and snaps within 16px of the peak of a recency-weighted density over those widths (half-life of eight releases, weights normalized to sum to one so each release takes share from the rest, last 40 kept). Moving slowly inside the snap zone unlocks it for precise placement, and Alt skips it. Width and history persist in `localStorage` under `storageKey`. `useSidebar()` exposes `width`, `samples`, `preferredWidth`, `drag`, and `resetResize`. `sidebarWidthDensity` and `learnedSidebarWidth` are exported for charting. Sidebar has its own docs page with a live chart of the learned width.
- Sheet slides 40px in from its edge over 320ms on `--ease-enter` while it fades and un-blurs from 4px in 200ms, and leaves in 200ms. The scrim fades on the same timing and no longer blurs the page. `SheetContent` now positions and animates a wrapper and draws the rounded surface inside it, so the Lisse shadow moves and fades with the panel instead of lingering. `className` still lands on the surface. Under reduced motion the sheet fades without sliding.
- Button takes `pill` to round any variant and size fully. Text buttons gain 2px of side padding so the label clears the curve, and icon sizes become circles. `buttonVariants` takes `pill` too.
- The primary button is a dark brown gradient, after SF Compute's: `#665146` at the top, flat `#3b2a21` from 36.79% to 60.86%, and `#503d33` at the bottom, with a deeper 68% border the fill shows through. Hover brightens it to 104%, and a press dims it to 95% while it scales in. The colors are new `--button-primary`, `--button-primary-gradient`, `--button-primary-border`, and `--button-primary-foreground` tokens, cream in dark mode.
- The radius ramp matches SF Compute: `xs` 6px, `sm` 8px, `md` 10px, `lg` 12px, `xl` 14px, `2xl` 18px. `CORNERS.xl` and `CORNERS["2xl"]` follow at 14 and 18. Radius now follows height: buttons, inputs, textareas, and select triggers at 32 and 36px use `rounded-sm`, their 24 and 28px sizes use `rounded-xs`, and sidebar items, select items, list rows, and the Fluid Hover fill use `rounded-sm`.
- Smooth corners no longer show the page behind a panel's corners. Once Lisse clips an element to its squircle, the `smooth-corners` item's CSS sets its `border-radius` to 0, so a `rounded-*` class on an `Elevated` panel or an overlay can't fight the clip.
- `useCornerRef` re-attaches Lisse when its element changes. Dialog, Select, Tooltip, Sheet, and Drawer popups mount after their component, so their squircles never applied and they showed square corners. Dialog's footer drops `rounded-b-xl` and follows the clip.
- Sheet floats 8px in from the window edge on every side it touches, with smooth corners on all four corners instead of only the free edge.
- Dialog, Sheet, and Drawer portals sit at `z-50`. Lisse isolates the portal to anchor its effects, which trapped the popup's own `z-50` inside it, so fixed page elements with any positive z-index painted over the overlay.
- Fluid Hover joins the system. `useFluidHover` and `FluidHoverHighlight` in `lib/fluid-hover.tsx` draw one fill that glides between `data-fluid-hover-item` targets on a 320ms `cubic-bezier(0.32, 0.72, 0, 1)` transform, fades in fresh where the pointer enters, and snaps under reduced motion. `SidebarMenu` uses it, so menu buttons no longer fill on their own hover.
- List is a new component: rows of links 44px tall between hairline rules, a title and a right-hand `meta`, and a Fluid Hover fill 5px inside each row.
- The charts are gone. `components/ui/charts` and its fourteen charts are replaced by `data-display`: `BarChart` (grouped bars on a tick grid, with totals and hatched partial values), `ChartKey`, and the `ChartGrid` layout. Bar charts use the app's font, pastel blue, green, and purple fills with a deeper stroke on a hairline grid, and a value tag on hover. Cards sit on `bg-card` with a `border-border` edge, `rounded-xl` corners, and no shadow. `@scritto/react` is no longer a dependency.
- Sidebar matches the docs navigation. Menu items rest in muted text at medium weight, fill to 60% accent on hover, and scale to 97% on press. The active item keeps the full accent fill. Group labels are plain `text-xs`, groups sit 24px apart, the sidebar is 15rem wide, and the edge border is gone.
- Textarea is a Prometheus component. It shares Input's border, hover, focus, read-only, invalid, and disabled looks, and grows with its text between `rows` (default 3) and `maxRows` (default 12). `count="characters"` counts against `maxLength` and `count="words"` against a soft `maxWords`. `resizable` makes the bottom edge a grab handle that sets the height in whole lines by drag or arrow keys, between `rows` and `maxRows`. Cmd+Enter or Ctrl+Enter submits the parent form. In a form, use `FormTextarea`, which is wired like `FormInput`.
- Icons are now Heroicons. Controls use the 16px solid set (`@heroicons/react/16/solid`), and Empty and Error icons use the 24px outline set. Registry items depend on `@heroicons/react` instead of `lucide-react`. Renamed icons include `XIcon` to `XMarkIcon`, `SearchIcon` to `MagnifyingGlassIcon`, `MailIcon` to `EnvelopeIcon`, and `PanelLeftIcon` to `Bars3Icon`. Table column `meta.icon` takes any component that accepts `className`, so it no longer depends on Lucide's types.
- Input is a Prometheus component. It has `sm`, `default`, and `lg` sizes, `start` and `end` slots, `pending` for a check on the value, and `invalid`. Read-only and disabled have their own looks. In a form, use `FormInput`: it links the label, sets `invalid` and `aria-describedby`, and goes read-only while the form submits. `FormField`'s render prop gets a third argument, `control`, with a unique `id`, `aria-invalid`, and `aria-describedby`. Spread it onto the control instead of setting `id={field.name}`, so two forms on one page don't share ids.
- Button's filled `default` is now `variant="primary"`. The new `default` is a white surface with a short shadow, lifted two steps above its substrate so it stays lighter inside menus and dialogs. Make it the button you reach for, and use the other variants as fallbacks. The `outline` variant is gone; use the default. `secondary` is now `variant="outlined"`: a border with no fill.
- Skeleton is now [Skullet](https://skullet.lochie.me). It measures the loaded view into its skeleton, so nothing moves on reveal. `LoadingState` is gone: wrap the view in `Skeleton` with `loading`, or pass `data` and `sample`. Sidebar uses `SkeletonBox`.

## 0.2.0

- App shell and sidebar. App screens start from AppShell. The sidebar follows `usePrometheus().isMobile`.
- `LoadingState`, `Empty`, and `ErrorState` for page states. Wrap the loaded view and set `loading` so the slot eases to the new height. A submitting button uses Spinner and stays disabled.
- Form pattern on react-hook-form and zod: field errors, a root error, and a pending submit. Entered values stay when submit fails.
- Registry source files carry `// @prometheus 0.2.0`. `base` installs `PROMETHEUS.md` with the same version.
- Type ramp from `text-xs` through `text-5xl`, with size, line-height, and tracking on each step. Titles from `text-xl` use `font-display`. Long-form copy uses `prose`.
- Breakpoint tokens `sm` through `xl`. `usePrometheus().isMobile` follows `breakpoints.md`.
- Charts: line, bar, donut, stream, brush, waffle, slope, sparkline, gauge, heatmap, counter, ridgeline, treemap, and split bar. Series use the chart color tokens.

Copying a registry file does not update projects that already installed it. Compare the stamp in the file with this changelog, then re-add items that are behind.
